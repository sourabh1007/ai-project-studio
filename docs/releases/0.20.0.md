# AI Project Studio 0.20.0

**Unsigned prerelease, not production-qualified.** Windows may show an
unknown-publisher or SmartScreen warning. macOS installers are ad-hoc signed,
not notarized; Gatekeeper may require explicit approval. No automatic-update
feed is published. Back up important workspace data before trying this release.

## Tracked work and Planner

- Export automatically tracked work for a calendar day, Monday-Sunday week,
  or calendar year in Markdown, JSON or CSV.
- Exports include assigned dates, current status and notes across repositories,
  including completed tracked tasks. Manual, backlogged and deleted tasks are
  excluded. No new AI call or raw conversation export is required.
- CSV fields protect against spreadsheet formula interpretation. Reported
  completion remains distinct from independently verified work.

## Monitoring and navigation

- Inspect durable app-owned admission, preparation and dispatch phases for
  cold and warm meta attempts. Provider-internal retries remain unavailable
  when the provider does not expose them.
- MCP observations preserve explicitly reported success/failure; missing and
  historical outcomes remain unknown. Server names do not prove configuration
  revision identity.
- Drill from workspace UTC-day usage into bounded session pages, including
  retained billing whose original sessions are no longer available.
- Open an operation's known owning agent or originating workspace session,
  visit Metasession capacity settings, and return without losing originating
  controls, drafts or workspace tab/split selection.
- Monitoring consumers share one injected live stream per window. Detached
  windows do not advertise unsupported cross-owner navigation.
- Bug Bash keeps bounded immutable completed-run scenario metadata, separate
  from editable current scenarios and full evidence. Legacy history is not
  reconstructed.

## Workspace and reliability

- Azure DevOps organization selection scopes searchable project lists.
  Explicit sign-in persists native credential-manager account bindings for
  reuse across application launches.
- Includes the accumulated workspace, queue visibility, terminal, recovery,
  provider-readiness and shutdown presentation improvements since 0.19.9.
- Fixes cross-platform MCP diagnostics test races without weakening coverage
  thresholds or globally extending test timeouts.

## Release evidence and limitations

The existing release workflow gates the exact tagged commit on Windows, Linux,
Apple Silicon macOS and Intel macOS before building Windows x64 and macOS
arm64/x64 installers. Published candidate manifests bind installer hashes to
that commit and workflow run.

Passing source tests and isolated synthetic packaged smoke checks does not
certify real provider inference, native input/focus, upgrades, signing,
notarization or production readiness. Installer provenance remains unqualified;
this prerelease is not marked latest or promoted to stable.
