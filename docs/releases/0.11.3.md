# AI Project Studio 0.11.3

**Unsigned prerelease.** These installers are not production-qualified. Windows may show an unknown-publisher or SmartScreen warning. The macOS build is unsigned and not notarized; Gatekeeper may block it. Version 0.10.3 remains the stable release. No automatic-update feed is published for this prerelease.

## Fixes

- Fixed a process leak that could make the app appear broadly unstable over time ("Service unavailable", request timeouts, and a false "GitHub · sign in required" state that persisted even after reinstalling the GitHub CLI). The MCP tool-server child process (`studio-mcp-server.js`, spawned per provider session) never noticed when its parent CLI process exited, so it never exited itself — on a machine with weeks of use this silently accumulated dozens of zombie processes and multiple GB of memory pressure, which in turn starved the real backend and made short-lived commands like `gh auth status` time out and get misread as "not signed in". The process now exits cleanly as soon as its parent's pipe closes, so it can no longer accumulate.
- If you were affected by this before updating, restart the app after installing 0.11.3; any already-leaked processes from prior versions are not retroactively cleaned up by this fix and should be closed manually (Task Manager / Activity Monitor) if still present.

## Also included (from 0.11.1 / 0.11.2)

- Fixed the installer packaging defect that shipped 0.11.0 without the backend's production dependencies ("Backend did not start in time" on every fresh install).
- Fixed a shutdown deadlock where a crashed backend without confirmed cleanup could leave the app stuck on "Closing safely" forever.
- Fixed a backend crash when an optional CLI (such as `agency`) is not available on the machine's PATH.
- Fixed a packaging defect that made every installed app show "Cannot GET /" instead of the app.

## Known limitations

- A related, separate leak (orphaned provider CLI session processes not being reconciled after a backend restart or crash) is not fixed by this release; it is being tracked and addressed as part of an active, larger session-reconciliation effort.
- Full packaged/native, upgrade/restore, and supported-platform qualification is not complete. Signing is intentionally omitted from this prerelease.
- Automatic retained-image cleanup is unavailable; deletion is manual because provider-history references cannot be proven absent.
- Automatic installation remains withdrawn in favor of guided release-page installation.
- Long-duration soak runs were waived, not completed.

Back up important workspace data before trying this prerelease. Installer provenance manifests are included; their pending qualification status remains accurate after publication.
