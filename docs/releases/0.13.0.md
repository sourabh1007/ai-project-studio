# AI Project Studio 0.13.0

**Unsigned prerelease.** These installers are not production-qualified. Windows
may show an unknown-publisher or SmartScreen warning. The macOS build is unsigned
and not notarized; Gatekeeper may block it. Version 0.10.3 remains the stable
release.

**Upgrade note:** the entire `0.11.x` line is superseded and marked known-bad.
Upgrade past it.

This minor release makes the signed-in plan's AI-credit budget populate
reliably, and rebuilds Settings into a set of focused, legible sections.

## Plan usage

- **The plan AI-credit budget now populates.** The `/usage` probe command and
  the PTY capture that scrapes it were corrected so the status bar shows used /
  total / available credits and the reset window instead of a permanent
  "unavailable".
- A failed capture is reported as a genuine failure rather than being
  indistinguishable from "no snapshot yet", and the probe is configurable.

## Settings

- **Settings is split into discrete sections** (appearance, metasession pools,
  prompts & commands, network activity, worktrees, retained images, diagnostics,
  software update) behind a single settings page, so each area loads and reads on
  its own.
- **Popups and overlays are fully opaque** instead of washed-out and hard to
  read.
- **Status and progress icons animate** where they were previously frozen.
- Light-theme contrast fixes make previously invisible controls legible.

## Reliability

- At the release commit the gated source builds cleanly and passes the backend
  and UI coverage gates at 100% line/branch/function/statement coverage.

## Known limitations

- Live GitHub and Azure DevOps operations, installed Copilot/Agency CLI
  processes, authenticated MCP child servers, and a real warm metasession under
  provider load still require an environment qualification run.
- Credits remain genuinely unknown for providers that do not report usage; the
  view shows the unknown state and the tokens it does have rather than inventing a
  cost.
- Windows and macOS installer upgrade/restore qualification is not complete.
  Signing is intentionally omitted from this prerelease; macOS cannot
  self-install updates until signing and notarization are available.

Back up important workspace data before trying this prerelease. Installer
provenance manifests are included and retain their unqualified status.
