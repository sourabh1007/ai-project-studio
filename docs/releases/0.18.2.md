# AI Project Studio 0.18.2

**Unsigned prerelease.** These installers are not production-qualified. Windows
may show an unknown-publisher or SmartScreen warning. The macOS build is unsigned
and not notarized; Gatekeeper may block it. No automatic-update feed is published.

This release delivers the [0.18.0 feature set](0.18.0.md): persistent Review Board
results and confirmed PR approval, separate MCP tools/authentication/configuration
controls, MCP usage charts, live resource monitoring, asynchronous worktree
cleanup, and durable appearance preferences.

The 0.18.0 and 0.18.1 pipelines stopped before publishing installers. Their tags
are preserved. This release includes the following verification corrections:

- Worktree cleanup and storage-path normalization explicitly test Windows,
  Linux, and macOS casing behavior on every runner.
- The bulk PR selection test checks the exact selected PRs and ten-PR limit
  without repeated full-document accessibility searches.

Windows and Linux CI passed on the corrected source before this version bump.
The release workflow independently gates the exact release commit on Windows,
Linux, and macOS. Coverage thresholds and timeouts are unchanged.

The known limitations documented for 0.18.0 still apply. Back up important
workspace data before trying this prerelease. Installer provenance manifests
retain their unqualified status.
