# AI Project Studio 0.17.4

**Unsigned prerelease.** These installers are not production-qualified. Windows
may show an unknown-publisher or SmartScreen warning. The macOS build is unsigned
and not notarized; Gatekeeper may block it. Version 0.10.3 remains the stable
release.

**Upgrade note:** the entire `0.11.x` line is superseded and marked known-bad.
Upgrade past it.

A patch release focused on MCP observability, connection health, and detachable
workspace windows.

## MCP servers

- **Usage metering** — MCP tool calls are now proxied and metered, with usage
  rolled up and surfaced at both the feature and IDE levels so per-server tool
  activity is finally visible where the rest of the analytics live.
- **Live connection status** — the MCP manager shows real connection state and
  tool availability per server, with clear color coding and icons.
- **Auth surfaced and one-click** — servers that require authentication now say
  so directly in the UI, and can be authenticated in place.

## Workspace

- **Detachable windows** — Sessions and Agent boards can be popped out into their
  own OS window and returned to the IDE with a single click.
- **Responsive modals** — popups now scale to the available screen size instead
  of clipping on smaller displays.
- **Readable MCP tool details** — tool descriptions and status text in the MCP
  tools view use higher-contrast colors.

## Cleanup

- **Scratchpad no longer ships by default** — the scratchpad feature is no longer
  installed automatically on a fresh install.

## Reliability

- At the release commit the gated source builds cleanly and passes the backend
  and UI suites plus the desktop harness regression suite.

## Known limitations

- Windows and macOS installer upgrade/restore qualification is not complete.
  Signing is intentionally omitted from this prerelease.

Back up important workspace data before trying this prerelease. Installer
provenance manifests are included and retain their unqualified status.
