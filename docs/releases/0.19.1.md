# AI Project Studio 0.19.1

**Unsigned prerelease.** These installers are not production-qualified. Windows
may show an unknown-publisher or SmartScreen warning. The macOS build is
**ad-hoc signed but not notarized** (no Apple Developer ID yet); Gatekeeper still
gates it behind the quarantine prompt. No automatic-update feed is published.

> **macOS: "AI Project Studio is damaged and can't be opened"?**
> That message appears when macOS quarantines a downloaded app it can't verify.
> After dragging the app to `/Applications`, clear the quarantine flag once:
>
> ```bash
> xattr -dr com.apple.quarantine "/Applications/AI Project Studio.app"
> ```
>
> Then open it normally. This build is ad-hoc signed, so Apple Silicon no longer
> reports it as "damaged" — you'll get the standard "unidentified developer"
> prompt instead, which the command above resolves.

This patch release focuses on the **New Task** agent — a less verbose, more
visual planning experience — and polishes Metasession provider selection.

## New Task planning

- **Interactive Describe step and consent-based refine**: the planner takes your
  prompt and reply and proposes plan changes that you approve before they apply.
- **Animated analysis timeline**: the Plan tab now shows the analysis steps as
  they happen, in real time, with parallel work rendered side by side and a
  clean, full-width proposed plan you can download.
- **Analysis trail persists**: the Plan timeline survives revisiting a task.
- **Feature renamed during planning**: the planner derives a concise title and
  summary; the task's feature is renamed to that title, the exported plan
  document uses the same heading, and the full plan is committed to the branch
  as `NEWTASK-PLAN.md`. The pull-request description is reduced to a concise
  problem and solution summary that points at the committed plan document.

## Metasession and status bar

- **Provider selector in Metasession settings**: pick the provider alongside the
  model for each pool.
- **Status bar reflects the live provider** after an identity change instead of
  showing a stale value.

Everything from 0.19.0 (and earlier) is retained: the MCP management overhaul,
reliably injected shared workspace context, honest session numbering with hidden
background "meta" sessions, modernized motion and scrollbars, and the hardened
terminal/desktop robustness fixes.

The release workflow independently gates the exact release commit on Windows,
Linux, and macOS. Backend and UI coverage remain at 100%; the desktop harness
regression suite passes. Coverage thresholds and timeouts are unchanged.

The known limitations documented for 0.18.0 still apply. Back up important
workspace data before trying this prerelease. Installer provenance manifests
retain their unqualified status.
