# AI Project Studio 0.11.6

**Unsigned prerelease.** These installers are not production-qualified. Windows
may show an unknown-publisher or SmartScreen warning. The macOS build is unsigned
and not notarized; Gatekeeper may block it. Version 0.10.3 remains the stable
release.

This patch completes the queued workflow and review fixes, simplifies all
headless AI work onto one observable metasession pool, and adds persisted
integration qualification across the application's major capability groups.

## Fixes

- **Review Board analysis no longer fails every perspective when one warm
  metasession is unhealthy.** Provider failures are retried unless the caller
  cancelled, the final attempt is forced onto a cold session, and an exhausted
  review surfaces the real provider error instead of a generic internal error.
- **Features can be dragged into nested sub-categories.** Collapsed destinations
  expand while hovered, and invalid self/descendant targets are excluded before
  a drop reaches the backend.
- **Session bootstrap is now visually seamless.** Repository context, shared
  context, MCP configuration, and skills are still recorded for summaries and
  observed by internal recovery logic, but their full injected text is hidden
  from terminal scrollback and replaced by a concise application-status line.
- **Warm-pool size changes remain visible while applying.** Settings shows the
  saved target and each metasession's live warming, ready, busy, or stopping
  state instead of appearing to revert the requested count.
- **Plan usage remains visible while it is being captured or temporarily
  unavailable**, rather than disappearing from the status bar.
- **Update discovery scans published releases rather than relying on the latest
  release endpoint**, so prerelease patch notifications are detected.
- **Ctrl+P Quick Open has its own command identity**, eliminating duplicate keys
  in the keyboard-shortcuts view without changing its palette behavior.

## Reliability and diagnostics

- All headless AI features—repository analysis, summaries, task plans, PR
  analysis, Review Board, monitors, reports, and subagents—draw from one shared,
  configurable metasession pool.
- Backend supervisor failures are persisted in a bounded diagnostic log. Settings
  shows why the backend stopped, recent renderer/API failures, and a restart
  action.
- Plan usage capture, pool status, and saved metasession operations expose
  explicit capturing, unavailable, interrupted, and completed states rather than
  silently shaping failure as success.

## Integration qualification

This release adds persisted vertical integration suites for:

- repository, feature, nested-feature, sub-category, session, shared-context,
  skill, prior-memory, and session-bootstrap behavior;
- automation scheduling, reports, subagents, lifecycle controls, durable
  operations, and restart recovery;
- PR feature creation, review persistence, deterministic change graphs, Review
  Board retries, comments, approval, description export, usage, and cleanup;
- MCP configuration, tool discovery/toggling, restart, and live session reload;
- usage normalization, credit calculation, aggregation/detail reads, IDE AI,
  event streaming, and saved metasession results;
- warm/cold routing, forced-cold retry, process status, and live pool resizing;
- assembled Settings, diagnostics, retained images, worktrees, appearance
  persistence, navigation, command palette, and Electron preload bridges.

The exact capability-to-test matrix and environment boundaries are documented in
`docs/integration-qualification.md`.

At the release commit, the qualified source gates contain 3,052 passing backend
tests with 100% line/branch/function/statement coverage, 1,188 passing UI tests
with 100% gated coverage, 169 passing desktop harness tests, a clean production
build, and a passing rebuilt packaged synthetic-startup smoke.

## Known limitations

- Live GitHub and Azure DevOps operations, installed Copilot/Agency CLI
  processes, authenticated MCP child servers, and a real warm metasession under
  provider load still require an environment qualification run. Their request
  contracts, state transitions, persistence, retries, and failure handling are
  covered by deterministic integration tests.
- The packaged smoke uses an isolated synthetic backend. It verifies packaged
  startup, preload/backend identity, and cooperative cleanup, not real provider
  availability or sustained load.
- Windows and macOS installer upgrade/restore qualification is not complete.
  Signing is intentionally omitted from this prerelease; macOS cannot
  self-install updates until signing and notarization are available.
- Azure `ci-pipeline` automation polling is not implemented. Use an HTTP check
  against the Azure DevOps REST API or a shell check using `az`.
- Automatic retained-image cleanup remains unavailable; deletion is manual
  because provider-history references cannot be proven absent.

Back up important workspace data before trying this prerelease. Installer
provenance manifests are included and retain their unqualified status.
