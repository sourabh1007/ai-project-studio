# AI Project Studio 0.19.7

**Unsigned prerelease.** These installers are not production-qualified. Windows
may show an unknown-publisher or SmartScreen warning. The macOS build is
**ad-hoc signed but not notarized** (no Apple Developer ID yet); Gatekeeper still
gates it behind the quarantine prompt. No automatic-update feed is published.

> **macOS: "AI Project Studio is damaged and can't be opened"?**
> That message appears when macOS quarantines a downloaded app it can't verify.
> After dragging the app to `/Applications`, clear the quarantine flag once:
>
> ```bash
> xattr -dr com.apple.quarantine "/Applications/AI Project Studio.app"
> ```
>
> Then open it normally. This build is ad-hoc signed, so Apple Silicon no longer
> reports it as "damaged" — you'll get the standard "unidentified developer"
> prompt instead, which the command above resolves.

This release sharpens the **Planner** quick-add experience and fixes session
naming after the app rebrand.

## Planner quick-add

- **Multi-line tasks**: the quick-add box is now a full-width, auto-growing
  text area. **Enter** adds the task; **Shift+Enter** inserts a newline, so a
  task can span several lines with its formatting preserved.
- **No title length limit**: long tasks — including pasted pull-request URLs —
  can be captured. The empty-title guard remains.
- **Quieter summaries**: the AI task summary now runs as an internal
  metasession instead of creating a hidden "Planner summaries" feature, so it
  no longer resurrects the Scratchpad. Its credit usage is still attributed and
  visible in Usage.

## Session names

- **Meaningful names restored**: after the app was rebranded, custom session
  names stored only in the renderer were lost, leaving generic "Session #N"
  labels. Sessions now fall back to the CLI work-title or first prompt in the
  explorer and tab labels, so names stay meaningful across updates.
- **Actionable launch errors**: launching a task outside a git repository now
  shows a clear, actionable message instead of a raw git error.

Everything from 0.19.6 (and earlier) is retained: the dated Planner with
filters-on-top, priorities, backlog, launches, and Markdown/HTML AI summaries;
live prompt history with copy/download; clean terminal copy-paste; and per-tool
MCP usage reporting.

The release workflow independently gates the exact release commit on Windows,
Linux, and macOS. Backend and UI coverage remain at 100%; the desktop harness
regression suite passes. Coverage thresholds and timeouts are unchanged.

The known limitations documented for 0.18.0 still apply. Back up important
workspace data before trying this prerelease. Installer provenance manifests
retain their unqualified status.
