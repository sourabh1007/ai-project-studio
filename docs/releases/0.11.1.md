# AI Project Studio 0.11.1

**Unsigned prerelease.** These installers are not production-qualified. Windows may show an unknown-publisher or SmartScreen warning. The macOS build is unsigned and not notarized; Gatekeeper may block it. Version 0.10.3 remains the stable release. No automatic-update feed is published for this prerelease.

## Fixes

- Fixed a packaging defect that shipped the Windows/macOS installers in 0.11.0 without the backend's production dependencies, causing every fresh install to fail to start with "Backend did not start in time." The desktop packaging configuration now stages the backend's `node_modules` in a location the installer builder cannot silently strip.
- Fixed a shutdown deadlock: if the backend process ever exited without confirming cooperative cleanup, the app could get stuck showing "Closing safely" forever with no way to close it. Startup failures are now detected immediately (instead of only after a fixed timeout) and are captured to a bounded `desktop-startup.log` for diagnosis. A backend that has already exited without confirmed cleanup now offers an explicit "Close app" recovery option instead of hanging.
- Fixed a backend crash that could occur when an optional CLI (such as `agency`) is not available on the machine's PATH: a missing executable is now handled gracefully instead of crashing the entire backend process.

## Known limitations

- Full packaged/native, upgrade/restore, and supported-platform qualification is not complete. Signing is intentionally omitted from this prerelease.
- Automatic retained-image cleanup is unavailable; deletion is manual because provider-history references cannot be proven absent.
- Automatic installation remains withdrawn in favor of guided release-page installation.
- Long-duration soak runs were waived, not completed.

Back up important workspace data before trying this prerelease. Installer provenance manifests are included; their pending qualification status remains accurate after publication.
