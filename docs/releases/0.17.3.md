# AI Project Studio 0.17.3

**Unsigned prerelease.** These installers are not production-qualified. Windows
may show an unknown-publisher or SmartScreen warning. The macOS build is unsigned
and not notarized; Gatekeeper may block it. Version 0.10.3 remains the stable
release.

**Upgrade note:** the entire `0.11.x` line is superseded and marked known-bad.
Upgrade past it.

A patch release that brings the startup splash emblem to life.

## Startup splash

- **Revolving orbital emblem** — the boot splash now shows a three-ring orbital
  system: concentric rings at different radii, speeds, and directions each carry
  glowing planet dots that revolve around the AI icon, so the launch screen reads
  as actively working rather than static.
- **Motion preserved under reduced motion** — the emblem keeps revolving (at a
  gentler pace) when the system requests reduced motion, matching the existing
  treatment of the activity and loading-track indicators so the splash never
  looks stalled.

## Reliability

- At the release commit the gated source builds cleanly and passes the backend
  and UI coverage gates at 100% line/branch/function/statement coverage, plus
  the desktop harness regression suite.

## Known limitations

- Windows and macOS installer upgrade/restore qualification is not complete.
  Signing is intentionally omitted from this prerelease.

Back up important workspace data before trying this prerelease. Installer
provenance manifests are included and retain their unqualified status.
