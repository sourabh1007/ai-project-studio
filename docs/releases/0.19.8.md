# AI Project Studio 0.19.8

**Unsigned prerelease.** These installers are not production-qualified. Windows
may show an unknown-publisher or SmartScreen warning. The macOS build is
**ad-hoc signed but not notarized** (no Apple Developer ID yet); Gatekeeper still
gates it behind the quarantine prompt. No automatic-update feed is published.

> **macOS: "AI Project Studio is damaged and can't be opened"?**
> That message appears when macOS quarantines a downloaded app it can't verify.
> After dragging the app to `/Applications`, clear the quarantine flag once:
>
> ```bash
> xattr -dr com.apple.quarantine "/Applications/AI Project Studio.app"
> ```
>
> Then open it normally. This build is ad-hoc signed, so Apple Silicon no longer
> reports it as "damaged" — you'll get the standard "unidentified developer"
> prompt instead, which the command above resolves.

This release polishes the **Planner**, refreshes the app **brand**, improves the
Review Board **commenting** experience, and fills in missing **MCP usage** stats.

## Planner

- **Date-hero header**: the viewed date is now the animated hero of the page —
  weekday eyebrow, gradient date, and a relative pill (Today / Tomorrow / "in N
  days"). Planner branding stays in a compact brand bar with the toolbar actions
  inline, so the header no longer wastes space and more tasks are visible
  without scrolling.
- **Liquid day navigation**: changing the day is a true, directional carousel —
  the incoming day slides in from the right (forward) or left (back) with a
  smooth easeOutExpo motion.
- **Richer import**: importing from Azure DevOps and GitHub now pulls in
  work-item descriptions, pull-request bodies, and ADO work-item comments, with
  assignee / state / area / iteration / tag filters on the import dialog.
- **Deletions reflect back**: deleting a feature or session now clears the
  originating planner task's launch link, so the Planner stays in sync and the
  task can be launched again.

## Review Board

- **"Leave a Comment"**: the "Post and Resolve" action is renamed to "Leave a
  Comment".
- **Formatting toolbar**: the comment composer gains bold, italic,
  strikethrough, inline code, code block, link, bullet list, and quote controls,
  plus write/preview tabs, with multi-line input.

## Brand

- **Refreshed app icon**: a more detailed, aligned, 3D-style icon across the
  desktop packaging (Windows, macOS, Linux) and the UI chrome, drawn through a
  shared brand-mark component.

## Usage

- **MCP timing restored**: per-server MCP usage now reports total call time and
  first/last-call timestamps. Durations are derived from each call's completion
  event; remote servers without a completion event show a best-effort lower
  bound.

Everything from 0.19.7 (and earlier) is retained: the multi-line Planner
quick-add with unlimited titles, work-title session names, dated Planner with
filters, priorities, backlog, launches, and Markdown/HTML AI summaries.

The release workflow independently gates the exact release commit on Windows,
Linux, and macOS. Backend and UI coverage remain at 100%; the desktop harness
regression suite passes. Coverage thresholds and timeouts are unchanged.

The known limitations documented for 0.18.0 still apply. Back up important
workspace data before trying this prerelease. Installer provenance manifests
retain their unqualified status.
