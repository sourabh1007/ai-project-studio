# AI Project Studio 0.17.1

**Unsigned prerelease.** These installers are not production-qualified. Windows
may show an unknown-publisher or SmartScreen warning. The macOS build is unsigned
and not notarized; Gatekeeper may block it. Version 0.10.3 remains the stable
release.

**Upgrade note:** the entire `0.11.x` line is superseded and marked known-bad.
Upgrade past it.

A patch release that clarifies Azure DevOps identity in the sidebar and stops
the terminal from garbling scrollback mid-session.

## Fixes

- **Azure DevOps identity** — the sidebar pill now shows the signed-in
  **username** (like the GitHub pill), remembers it across silent re-checks, and
  **auto-detects the organization** from an Azure DevOps repository already in
  the workspace. A user who authenticated through a session no longer has to
  retype an org for the pill to resolve, and the connection shows a clean
  `org / repo` label instead of a raw URL.
- **Terminal renderer self-heal** — on GPU context loss (sleep/resume, driver
  reset), the terminal now recreates its WebGL renderer instead of silently
  falling back to the DOM renderer. This fixes garbled scrollback that
  reappeared mid-session until the app was restarted.

## Reliability

- At the release commit the gated source builds cleanly and passes the backend
  and UI coverage gates at 100% line/branch/function/statement coverage.

## Known limitations

- Azure DevOps auto-detection only resolves an identity when an Azure DevOps
  repository is present in the workspace; without one, the org must still be
  entered once. Azure tokens are organization-scoped, so a login performed
  entirely outside the workspace cannot always be detected silently.
- Windows and macOS installer upgrade/restore qualification is not complete.
  Signing is intentionally omitted from this prerelease.

Back up important workspace data before trying this prerelease. Installer
provenance manifests are included and retain their unqualified status.
