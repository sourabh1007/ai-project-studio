# AI Project Studio 0.19.0

**Unsigned prerelease.** These installers are not production-qualified. Windows
may show an unknown-publisher or SmartScreen warning. The macOS build is
**ad-hoc signed but not notarized** (no Apple Developer ID yet); Gatekeeper still
gates it behind the quarantine prompt. No automatic-update feed is published.

> **macOS: "AI Project Studio is damaged and can't be opened"?**
> That message appears when macOS quarantines a downloaded app it can't verify.
> After dragging the app to `/Applications`, clear the quarantine flag once:
>
> ```bash
> xattr -dr com.apple.quarantine "/Applications/AI Project Studio.app"
> ```
>
> Then open it normally. This build is ad-hoc signed, so Apple Silicon no longer
> reports it as "damaged" — you'll get the standard "unidentified developer"
> prompt instead, which the command above resolves.

This minor release overhauls MCP server management, makes the shared workspace
context reliably reach every session, cleans up session numbering and background
"meta" sessions, modernizes the app's motion and scrollbars, and fixes a cluster
of terminal and desktop robustness bugs.

## MCP server management

- **Redesigned MCP cards**: each server now has an icon enable/disable toggle
  plus explicit auth and configure controls, and the toggle and auth-key state
  reflect the live server status rather than a stale snapshot.
- **Catalog toggles apply to running sessions**: enabling or disabling Agency's
  built-in MCP tools takes effect on already-running sessions, not just new ones.
- **Clearer organization**: MCP category labels were clarified ("This App"
  casing aligned), the unused Claude Code category is hidden, and sign-in-blocked
  monitors are surfaced with a sign-in control that actually signs in.
- **Quieter logs**: the "MCP usage log capture is partial" warning is now emitted
  at most once per source instead of flooding the console, and capture retries
  silently.

## Shared workspace context

- **Injected everywhere**: the editable workspace context is seeded with a
  standing response prompt, defaults are config-driven, blank documents are
  populated, and the context is now injected into every session — including
  background/meta sessions.
- **Delivery bug fixes**: bootstrap context is written with the required
  `applyTo` frontmatter (without which the Copilot/Agency CLI silently ignored
  it), the editor no longer drops an async-loaded base into an empty field, and
  the seed never writes an unvalidated config key.

## Sessions and numbering

- **Honest Session #N**: the explorer tab now matches the explorer row — the new
  session response returns the persisted row so its ordinal is correct — and
  hidden background meta sessions no longer consume the visible `Session #N`
  counter, so numbers stay contiguous.
- **Meta sessions tidied**: meta-kind sessions are labeled "Meta #N", legacy
  meta sessions are hidden on startup, and the default metasession provider is
  Agency when it is available until you choose otherwise.
- **Self-healing**: interactive sessions auto-restart when the CLI requests a
  restart, instead of leaving you to do it manually.

## Interface polish

- **Modernized motion and chrome**: smooth `linear()` easings, refined borders
  and icons, and professional scrollbars throughout.
- **Terminal scrollbar** is now an auto-hiding overlay, and a regression where
  standard scrollbar properties disabled the custom styling is fixed.
- Stray provider bars are gone and prompt-history motion is smoother.

## Terminal and desktop robustness

- **No more double paste**: on Windows the Edit menu's `Ctrl+V` accelerator could
  fire a second native paste on top of the renderer's own handling
  (electron/electron#18295), duplicating pasted text — most visibly on the first
  paste. The menu no longer registers that keyboard accelerator, so the renderer
  solely owns Ctrl+C/V while mouse-menu paste still works.
- **Hardened process spawner and MCP log capture** against benign spawn/IO
  failures so a transient error can no longer crash a background loop.
- **No stray console window**: packaged builds no longer flash a dev-only backend
  command prompt.

Everything from 0.18.10 (and earlier) is retained: identity-aware provider
exposure (Agency surfaces only for Microsoft-signed-in identities, otherwise
GitHub Copilot everywhere), installed-only CLI offering, per-session provider
badges, the consolidated System settings tab, persistent repository insights, the
free SignPath / optional Apple notarization signing paths, automatic
Node.js/Git/gh provisioning on first launch, the macOS "damaged" packaging fix,
and the deterministic release pipeline.

The release workflow independently gates the exact release commit on Windows,
Linux, and macOS. Backend and UI coverage remain at 100%; the desktop harness
regression suite passes. Coverage thresholds and timeouts are unchanged.

The known limitations documented for 0.18.0 still apply. Back up important
workspace data before trying this prerelease. Installer provenance manifests
retain their unqualified status.
