# AI Project Studio 0.18.6

**Unsigned prerelease.** These installers are not production-qualified. Windows
may show an unknown-publisher or SmartScreen warning. The macOS build is
**ad-hoc signed but not notarized** (no Apple Developer ID yet); Gatekeeper still
gates it behind the quarantine prompt. No automatic-update feed is published.

> **macOS: "AI Project Studio is damaged and can't be opened"?**
> That message appears when macOS quarantines a downloaded app it can't verify.
> After dragging the app to `/Applications`, clear the quarantine flag once:
>
> ```bash
> xattr -dr com.apple.quarantine "/Applications/AI Project Studio.app"
> ```
>
> Then open it normally. This build is ad-hoc signed, so Apple Silicon no longer
> reports it as "damaged" — you'll get the standard "unidentified developer"
> prompt instead, which the command above resolves.

This is a maintenance patch over 0.18.5. It carries the same feature set with the
macOS packaging fix baked in from a clean, monotonic version:

- **macOS opens without "damaged"**: the macOS build is ad-hoc signed
  (electron-builder `mac.identity: '-'`, Hardened Runtime disabled), so Apple
  Silicon no longer rejects the download as "damaged and can't be opened." It
  remains unnotarized — clear the quarantine flag once (see the note above) and
  it opens via the standard unidentified-developer prompt.
- **Green release pipeline**: the flaky prompts-editor UI test that intermittently
  failed on Linux is now deterministic (it scopes the save action to the edited
  field and waits for the control to enable), so the cross-platform CI and
  release gates pass reliably.

Also included (from 0.18.5):

- **Team-tab time in review**: the PR picker's Team tab shows how long each
  pull request has been open and adds a sort control to order a teammate's PRs —
  and the teammate groups themselves — by longest-in-review or newest, widening
  responsively so larger teams stay readable. Pull requests carry the provider's
  open timestamp (GitHub `createdAt`, Azure DevOps `creationDate`).
- **Right-click tab menu**: right-clicking an editor tab opens Close this, Close
  tabs to the left, Close tabs to the right, and Close all, with edge actions
  disabled at the ends of the strip.
- **Smoother Windows auto-update**: the update banner shows explicit installing
  and restarting phases with animated, reduced-motion-aware indicators, detects a
  stalled download, and only allows dismissal when no install is in flight.
- **Agency CLI update notice**: when the IDE's background "keep agency current"
  check actually installs a new version on start, the app shows a dismissible
  "Agency CLI updated" popup on open (with the previous → new version when
  known). A no-op "already latest" check stays silent.

The release workflow independently gates the exact release commit on Windows,
Linux, and macOS. Backend and UI coverage remain at 100%; the desktop harness
regression suite passes. Coverage thresholds and timeouts are unchanged.

The known limitations documented for 0.18.0 still apply. Back up important
workspace data before trying this prerelease. Installer provenance manifests
retain their unqualified status.
