# AI Project Studio 0.19.3

**Unsigned prerelease.** These installers are not production-qualified. Windows
may show an unknown-publisher or SmartScreen warning. The macOS build is
**ad-hoc signed but not notarized** (no Apple Developer ID yet); Gatekeeper still
gates it behind the quarantine prompt. No automatic-update feed is published.

> **macOS: "AI Project Studio is damaged and can't be opened"?**
> That message appears when macOS quarantines a downloaded app it can't verify.
> After dragging the app to `/Applications`, clear the quarantine flag once:
>
> ```bash
> xattr -dr com.apple.quarantine "/Applications/AI Project Studio.app"
> ```
>
> Then open it normally. This build is ad-hoc signed, so Apple Silicon no longer
> reports it as "damaged" — you'll get the standard "unidentified developer"
> prompt instead, which the command above resolves.

This patch release makes the terminal and **New Task** planning cleaner to work
with, adds emoji reactions to the Review Board, deepens MCP usage reporting, and
hardens session branch resolution.

## Terminal

- **Clean copy-paste**: selecting and copying CLI output no longer carries the
  terminal's box-frame, thread-rail gutter, or wrapped-row seam bars into the
  clipboard, so pasted text is clean without manual cleanup. Real inline pipes,
  `| grep-ready` output and ASCII markdown tables are preserved.
- **Reliable refit on collapse**: collapsing the workspace's side panel now
  refits the terminal even when stale selected text lingers, so text no longer
  stays stranded at the old narrow width until a restart.

## New Task

- **Live "plan is regenerating" indicator**: refining the plan in plain language
  now shows a slim, realtime bar on the plan card while the planner is actually
  working on your feedback — and only then.
- **Add to a feature that already has a pull request**: New Task can be started
  on a feature even when an earlier task already opened a PR.

## Review Board

- **Emoji reactions on comments**: react to PR review comments (👍 👎 😄 🎉 😕
  ❤️ 🚀 👀) on GitHub; Azure DevOps supports 👍 via comment likes.

## MCP

- **Per-tool usage breakdown**: usage reporting now attributes calls to the
  individual MCP tool and records each server's last-used timing.

## Sessions

- **Smarter default-branch resolution**: sessions now open on the repository's
  real default branch and no longer fail when a recorded ref is missing —
  falling back to the current branch instead of blocking.

Everything from 0.19.2 (and earlier) is retained: faster New Task
implementation, visibly parallel teamwork, the full-screen activity log with
per-file progress, accurate file diffs, PR-level review comments, and the longer
MCP tool-discovery timeout.

The release workflow independently gates the exact release commit on Windows,
Linux, and macOS. Backend and UI coverage remain at 100%; the desktop harness
regression suite passes. Coverage thresholds and timeouts are unchanged.

The known limitations documented for 0.18.0 still apply. Back up important
workspace data before trying this prerelease. Installer provenance manifests
retain their unqualified status.
