# AI Project Studio 0.18.1

**Unsigned prerelease.** These installers are not production-qualified. Windows
may show an unknown-publisher or SmartScreen warning. The macOS build is unsigned
and not notarized; Gatekeeper may block it. No automatic-update feed is published.

This release carries the [0.18.0 feature set](0.18.0.md): persistent Review Board
results and confirmed PR approval, separate MCP tools/authentication/configuration
controls, MCP usage charts, live resource monitoring, asynchronous worktree
cleanup, and durable appearance preferences.

The 0.18.0 pipeline stopped before building or publishing installers. Its tag
is preserved; 0.18.1 corrects the cross-platform verification failures:

- Cleanup tests explicitly exercise Windows, Linux, and macOS path-casing
  behavior on every runner, including duplicate and case-distinct paths.
- The bulk PR selection test avoids repeated full-document accessibility
  searches while still checking the ten-PR limit and exact confirmed selection.

Coverage thresholds, test timeouts, and release qualification gates are unchanged.
The known limitations documented for 0.18.0 still apply.

Back up important workspace data before trying this prerelease. Installer
provenance manifests retain their unqualified status.
