# AI Project Studio 0.12.0

**Unsigned prerelease.** These installers are not production-qualified. Windows
may show an unknown-publisher or SmartScreen warning. The macOS build is unsigned
and not notarized; Gatekeeper may block it. Version 0.10.3 remains the stable
release.

**Upgrade note:** the entire `0.11.x` line is superseded and marked known-bad.
Review Board runs on that line could hang while metasessions sat idle, progress
counters were off by one, several status icons never animated, and single-click
theme and single-click feature deletes required a second click. Upgrade to
0.12.0.

This minor release makes headless AI work share metasessions dynamically,
corrects and animates review progress, adds a live application-startup indicator,
lets features live inside sub-category folders, and rebuilds the saved-operations
view into a diagnostic surface.

## Dynamic metasession allotment

- **Review Board now scales across every available metasession.** When only one
  metasession is ready it is used and additional perspectives queue; when several
  are ready they run in parallel, with one instance reserved for interactive IDE
  work so the workspace stays responsive.
- **Queued perspectives pick up newly-added metasessions.** Scaling the warm pool
  up while a review is running now hands idle instances to waiting work on every
  subsequent scale-out, not just the first.
- **Reviews no longer run forever while metasessions sit idle.** Allotment,
  completion, and requeue are driven off live pool state so finished instances
  are returned and reused instead of stranding the run.

## Review progress and status

- **Progress counters are accurate.** "Reviewing N of M" reflects the perspective
  actually in flight instead of trailing by one.
- **Status icons animate.** Running, loading, and in-progress indicators across
  the app now show live motion rather than a frozen glyph.
- **Failed and interrupted operations explain themselves** instead of showing a
  bare error string.

## Application startup indicator

- The startup window shows an animated status icon and describes what the app is
  doing as it comes up — starting the backend, loading files, and restoring the
  workspace — instead of a static splash.

## Sub-category features

- **Features can be created, moved, and imported inside sub-category folders.**
  The explorer renders member features within their folder, a "New feature"
  folder action creates them in place, and the Move dialog offers sub-category
  folders as destinations.
- **Existing and PR-imported features can be dragged into sub-category folders.**
  Feature drops are accepted on folder headers and bodies, guarded so a feature
  cannot be nested into itself or an invalid target.

## Saved AI operations

- The **Saved AI operations** settings section is rebuilt as a status summary bar
  plus per-operation cards with a state-colored accent, canonical animated status
  badges, and plain-language captions.
- Each card surfaces the diagnostic detail that was previously missing: which
  metasession and session ran the work, the exact failure or interruption reason,
  time taken, model used, and token counts. Unknown usage is shown as genuinely
  unknown rather than zero cost.

## Interaction fixes

- **Theme switches on a single click**, and **deleting a feature takes a single
  confirmation** rather than two.
- Prompt previews load reliably and their popup is fully opaque instead of
  washed-out.
- Light-theme contrast fixes make previously invisible controls legible.

## Reliability

- Process termination now walks the full child process tree, so backend and CLI
  descendants are cleaned up instead of being orphaned.

At the release commit, the gated source contains 3,086 passing backend tests
with 100% line/branch/function/statement coverage, 1,220 passing UI tests with
100% gated coverage, and a clean production build.

## Known limitations

- Live GitHub and Azure DevOps operations, installed Copilot/Agency CLI
  processes, authenticated MCP child servers, and a real warm metasession under
  provider load still require an environment qualification run. Their request
  contracts, state transitions, persistence, retries, and failure handling are
  covered by deterministic tests.
- Credits remain genuinely unknown for providers that do not report usage; the
  view shows the unknown state and the tokens it does have rather than inventing a
  cost.
- Windows and macOS installer upgrade/restore qualification is not complete.
  Signing is intentionally omitted from this prerelease; macOS cannot
  self-install updates until signing and notarization are available.

Back up important workspace data before trying this prerelease. Installer
provenance manifests are included and retain their unqualified status.
