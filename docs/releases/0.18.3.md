# AI Project Studio 0.18.3

**Unsigned prerelease.** These installers are not production-qualified. Windows
may show an unknown-publisher or SmartScreen warning. The macOS build is unsigned
and not notarized; Gatekeeper may block it. No automatic-update feed is published.

This patch release fixes a batch of PR Review / Review Board defects and renames
the finding comment action:

- The reviewer now reads the pull request's existing review threads and their
  replies, so it skips concerns already raised and treats answered or resolved
  threads as addressed. Existing comments are best-effort context and never
  block generating a review.
- Opening a PR whose review row was orphaned no longer surfaces a raw
  "Unknown feature" error: the stale row is dropped and a fresh review is
  created automatically.
- Deleting a feature always purges its review row even when worktree cleanup
  fails, and orphaned reviews are reconciled on startup, so removed bulk-review
  folders no longer reappear after an IDE restart.
- The finding "Post and Resolve" action is now "Leave a comment" and only posts
  the comment. It marks the finding resolved in Review Board but leaves the PR
  thread open.

The release workflow independently gates the exact release commit on Windows,
Linux, and macOS. Backend and UI coverage remain at 100%; the desktop harness
regression suite passes. Coverage thresholds and timeouts are unchanged.

The known limitations documented for 0.18.0 still apply. Back up important
workspace data before trying this prerelease. Installer provenance manifests
retain their unqualified status.
