# AI Project Studio 0.20.3

**Unsigned prerelease, not production-qualified.** Windows may show an
unknown-publisher or SmartScreen warning. macOS installers are ad-hoc signed,
not notarized; Gatekeeper may require explicit approval. No automatic-update
feed is published. Back up important workspace data before trying this release.

## Faster Explorer and page navigation

- Keep the workspace mounted after its first visit. Returning from Planner,
  Settings or monitoring preserves Explorer expansion, scroll position, tabs and
  live terminals instead of restoring everything again.
- Opening a task from Planner shows its session immediately, even while older
  saved tabs are still being restored.
- Deleting, renaming or moving an Explorer item updates only that item (and a
  move's source and destination). Unrelated editors stay usable, and a stale
  network response can no longer bring back a deleted or renamed item.
- Pages show their previous results immediately from a short-lived, memory-only
  cache (one minute, 64 entries) while fresh data loads, and say when results
  are from the previous visit. MCP changes stay disabled until fresh
  configuration loads.
- Page code is preloaded in the background after startup and when hovering a
  dock icon, so switching pages usually renders without a loader. Page switches
  use a short fade that keeps terminal text sharp.

## Consistent loading feedback

- All main pages, panels and inline actions share the branded loader. Real
  completed/total steps show a percentage; unknown-duration work stays
  explicitly indeterminate. Longer loads show elapsed time.
- Loaders keep a calm rotation with Windows **Animation effects** off or the
  app's Reduced motion setting, so a working app never looks frozen. Only
  **Motion: Off** makes them static.
- Session consoles show a decorative loader while opening, which disappears as
  soon as the CLI writes output and never covers a CLI question.

## Appearance, fonts and console

- **IDE color schemes**: Nord, Dracula, Solarized, Gruvbox, Tokyo Night, Matrix
  and Cyberpunk, each with light and dark variants, applied before first paint.
  Every text, status and accent preset pair is contrast-tested.
- **Fonts**: separate interface, code and terminal fonts, including Inter,
  Space Grotesk, Chakra Petch, JetBrains Mono, Fira Code, Victor Mono, Share
  Tech Mono, VT323 and Press Start 2P. Fonts are bundled, so they render the
  same offline.
- **Console**: 15 color schemes plus **Match IDE**, and Tight/Default/Relaxed
  line spacing. Settings → Appearance now groups options with live previews.

## Accounts and icons

- The dock shows your GitHub profile picture and opens an **Accounts** dialog.
  Explorer's Accounts footer shows the picture and login.
- Azure DevOps rows show the Microsoft account's profile picture. The backend
  fetches it with the existing Azure DevOps sign-in and sends only the image to
  the UI; the token never leaves the backend. Generated placeholders keep
  initials.
- The desktop content policy now allows images only from GitHub's two avatar
  hosts, in addition to the app itself.
- Retry, sign-in and sign-out actions use consistent icons.

## Evidence and limitations

Local source validation passed the build/typecheck, backend (100%) and UI
coverage gates, and 280 desktop harness tests. Isolated Electron checks
confirmed that all 13 bundled fonts load, every IDE color scheme resolves, and
loaders animate under Windows reduced motion and stop only with Motion: Off.
The live app returned the real Azure DevOps profile picture.

These checks do not certify a real Review Board inference end-to-end.
The release workflow gates the exact tagged commit on Linux, Windows, Apple
Silicon macOS and Intel macOS before publishing Windows x64 and macOS arm64/x64
installers with SHA-bound candidate manifests. Signing, notarization and
production qualification remain separate; this prerelease is not marked latest.
