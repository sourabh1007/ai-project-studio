# AI Project Studio 0.18.7

**Unsigned prerelease.** These installers are not production-qualified. Windows
may show an unknown-publisher or SmartScreen warning. The macOS build is
**ad-hoc signed but not notarized** (no Apple Developer ID yet); Gatekeeper still
gates it behind the quarantine prompt. No automatic-update feed is published.

> **macOS: "AI Project Studio is damaged and can't be opened"?**
> That message appears when macOS quarantines a downloaded app it can't verify.
> After dragging the app to `/Applications`, clear the quarantine flag once:
>
> ```bash
> xattr -dr com.apple.quarantine "/Applications/AI Project Studio.app"
> ```
>
> Then open it normally. This build is ad-hoc signed, so Apple Silicon no longer
> reports it as "damaged" — you'll get the standard "unidentified developer"
> prompt instead, which the command above resolves.

This patch makes the app **set up its own dependencies on first launch**, so a
clean machine with nothing pre-installed can run it end to end.

- **Automatic Node.js runtime**: the backend needs a system Node (it uses
  `node:sqlite` and a native `node-pty` addon). If no compatible Node is present,
  the app now downloads a pinned, checksum-verified Node 24 runtime into its
  application-data folder on first launch instead of failing with a "Node.js was
  not found" error. The splash screen shows live download progress, and later
  launches reuse (or silently upgrade) the managed runtime.
- **Automatic GitHub CLI and Git**: the app also provisions the **GitHub CLI**
  (`gh`) on every platform and portable **Git** on Windows (macOS/Linux use the
  system Git that ships with the OS/Xcode CLT), each checksum-verified. The
  provisioned tools — including the `npm` bundled with Node, used by the
  Agency/Copilot CLI installers — are added to the backend's `PATH` so everything
  resolves without a manual install.
- **Clear setup progress and overrides**: each tool reports a labelled step on
  the splash ("Downloading GitHub CLI… 42%", etc.). Node is required; Git and gh
  are best-effort, so a transient download failure degrades a feature instead of
  blocking launch. Point the app at your own tools with `CW_NODE_BIN`,
  `CW_GH_BIN`, or `CW_GIT_BIN`.

Everything from 0.18.6 (and 0.18.5) is retained: the macOS "damaged" packaging
fix, the deterministic release pipeline, the Team-tab time-in-review sort, the
right-click tab menu, the smoother Windows auto-update, and the Agency CLI update
notice.

The release workflow independently gates the exact release commit on Windows,
Linux, and macOS. Backend and UI coverage remain at 100%; the desktop harness
regression suite passes. Coverage thresholds and timeouts are unchanged.

The known limitations documented for 0.18.0 still apply. Back up important
workspace data before trying this prerelease. Installer provenance manifests
retain their unqualified status.
