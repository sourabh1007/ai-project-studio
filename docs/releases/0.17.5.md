# AI Project Studio 0.17.5

**Unsigned prerelease.** These installers are not production-qualified. Windows
may show an unknown-publisher or SmartScreen warning. The macOS build is unsigned
and not notarized; Gatekeeper may block it. Version 0.10.3 remains the stable
release.

**Upgrade note:** the entire `0.11.x` line is superseded and marked known-bad.
Upgrade past it.

A patch release focused on quieter context delivery, terminal input and
rendering reliability, and self-healing MCP connections.

## Sessions & context

- **Silent repository context** — the composed repository/feature/skill context
  is now delivered to the CLI as a silently discovered custom-instructions file
  instead of being typed into the terminal as a wall of prompt text. Sessions
  start clean, with a single `Auto-injecting repository context…` status line
  instead of a scrollback full of seeded prompt. The file is re-prepared across
  self-recovery restarts and cleared on a genuine exit.
- **Feature-branch binding** — a session is bound to the feature branch it was
  started on. When work moves to a different branch, the switch is only carried
  out with explicit consent, so a session never silently follows an unexpected
  branch.

## Terminal reliability

- **Large pastes stream instead of breaking** — pasting a large block no longer
  trips the input-buffer limit and drops the connection. Input is chunked on
  UTF-8 code-point boundaries and streamed as flow-controlled frames, so an
  arbitrarily large paste is delivered smoothly without a reconnect.
- **Reliable copy** — copying from a session (including OSC 52 clipboard writes)
  now reliably lands on the system clipboard, so what the toast reports as copied
  is what actually pastes.
- **Steady viewport** — terminal rendering no longer flickers from atlas clears
  during streaming scroll, and the terminal container's scrollbar no longer
  flashes.

## MCP servers

- **Self-healing connections** — failing MCP connections are now diagnosed by a
  background metasession and repaired by following the fix the error prescribes,
  rather than staying stuck.
- **Windows stdio parity** — stdio MCP servers launch through a shell on Windows
  so a session's servers match the manager's.
- **Always-visible MCP section** — the feature dashboard always shows the MCP
  section with a clear empty state instead of hiding it when no server is
  configured.

## Repository insights

- **Parallel analysis** — repository report sections are analyzed concurrently by
  warmed background metasessions, so large-repository analysis completes without
  timing out and stays responsive while it runs.

## Accessibility

- **Screen-reader layout** — interactive sessions offer an opt-in plain layout
  for screen readers.

## Reliability

- At the release commit the gated source builds cleanly and passes the backend
  and UI coverage suites (100%) plus the desktop harness regression suite.

## Known limitations

- Windows and macOS installer upgrade/restore qualification is not complete.
  Signing is intentionally omitted from this prerelease.

Back up important workspace data before trying this prerelease. Installer
provenance manifests are included and retain their unqualified status.
