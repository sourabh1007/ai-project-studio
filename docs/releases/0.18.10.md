# AI Project Studio 0.18.10

**Unsigned prerelease.** These installers are not production-qualified. Windows
may show an unknown-publisher or SmartScreen warning. The macOS build is
**ad-hoc signed but not notarized** (no Apple Developer ID yet); Gatekeeper still
gates it behind the quarantine prompt. No automatic-update feed is published.

> **macOS: "AI Project Studio is damaged and can't be opened"?**
> That message appears when macOS quarantines a downloaded app it can't verify.
> After dragging the app to `/Applications`, clear the quarantine flag once:
>
> ```bash
> xattr -dr com.apple.quarantine "/Applications/AI Project Studio.app"
> ```
>
> Then open it normally. This build is ad-hoc signed, so Apple Silicon no longer
> reports it as "damaged" — you'll get the standard "unidentified developer"
> prompt instead, which the command above resolves.

This patch refines the multi-CLI experience so each CLI is surfaced only where it
is actually usable, and polishes diagnostics, provider defaults, and recovery
messaging.

- **Identity-aware provider exposure**: Agency — an internal Microsoft tool — is
  now available only when you are signed in with a Microsoft identity. Without
  it, the app falls back to GitHub Copilot everywhere (usage, the session
  dropdown, quota, settings, and metasession) with no trace of Agency. When a
  Microsoft identity is present, Agency becomes the default CLI across those same
  surfaces, including metasession.
- **Only offer installed CLIs**: a provider whose CLI is not installed or not
  usable is no longer shown as an option anywhere, so you can't open a session
  against a CLI that can't launch.
- **Network-aware new-session default**: the New session form now honors the
  identity/network-aware default provider instead of always preselecting the
  first registered CLI.
- **Per-session provider indicator**: each session in the explorer carries a
  compact provider badge (Copilot vs Agency) so you can tell at a glance which
  CLI a session runs.
- **Consolidated System settings**: the former General, Diagnostics, and System
  tabs are merged into a single **System** tab — app info, live backend health,
  provider status, software updates, logs, diagnostics, retained images, and
  review worktrees in one place with no duplicated controls.
- **Persistent repository insights**: repo insights are restored instantly on
  reopen and then refreshed in the background, surviving an app restart.
- **Friendlier recovery messaging**: the recoverable-session notices shown in the
  terminal are now short, plain-language, and actionable instead of raw
  `[auto-retry]` diagnostics.

Everything from 0.18.9 (and earlier) is retained: the free SignPath / optional
Apple notarization signing paths, multi-CLI provider support (GitHub Copilot +
Agency) with a network-aware default and a generalized first-run install gate,
automatic Node.js/Git/gh provisioning on first launch, the macOS "damaged"
packaging fix, and the deterministic release pipeline.

The release workflow independently gates the exact release commit on Windows,
Linux, and macOS. Backend and UI coverage remain at 100%; the desktop harness
regression suite passes. Coverage thresholds and timeouts are unchanged.

The known limitations documented for 0.18.0 still apply. Back up important
workspace data before trying this prerelease. Installer provenance manifests
retain their unqualified status.
