# AI Project Studio 0.18.4

**Unsigned prerelease.** These installers are not production-qualified. Windows
may show an unknown-publisher or SmartScreen warning. The macOS build is unsigned
and not notarized; Gatekeeper may block it. No automatic-update feed is published.

This patch release continues the PR Review / Review Board work with team-oriented
features, richer comment UX, avatars, and a durability fix for MCP auth state:

- **Review Board comment UX**: stale-check before posting, focus the relevant
  diff when opening a finding, and a markdown editor for comment bodies.
- **Bulk PR import**: importing open pull requests from a parent feature now
  nests them as sub-features instead of always creating parent features, and a
  PR that is already imported is reported with a clear "already imported"
  message instead of being silently skipped — including inside bulk imports.
- **Team picker tab**: a new Team tab in the PR picker, backed by a configurable
  "my team" roster that persists across restarts and filters the tab to those
  members' pull requests, with add/remove controls.
- **Avatars**: the Review Board header and PR picker show the pull request
  author's avatar and name, inline PR comments collapse to an author avatar
  bubble with a count badge, and the Accounts panel shows account avatars.
- **MCP auth persistence**: the last-known native MCP auth observation
  (ready/required/expired) is now stored durably and reloaded on startup, so the
  MCP Settings manager no longer resets every server to "unknown" after an IDE
  restart.

The release workflow independently gates the exact release commit on Windows,
Linux, and macOS. Backend and UI coverage remain at 100%; the desktop harness
regression suite passes. Coverage thresholds and timeouts are unchanged.

The known limitations documented for 0.18.0 still apply. Back up important
workspace data before trying this prerelease. Installer provenance manifests
retain their unqualified status.
