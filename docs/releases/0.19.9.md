# AI Project Studio 0.19.9

**Unsigned prerelease.** These installers are not production-qualified. Windows
may show an unknown-publisher or SmartScreen warning. The macOS build is
**ad-hoc signed but not notarized**; Gatekeeper may require explicit approval.
No automatic-update feed is published.

> **macOS: "AI Project Studio is damaged and can't be opened"?**
> After dragging the app to `/Applications`, clear the quarantine flag once:
>
> ```bash
> xattr -dr com.apple.quarantine "/Applications/AI Project Studio.app"
> ```
>
> Then open it normally. This does not notarize or production-qualify the app.

This patch improves workspace clarity and accessibility, preserves existing
checkouts, separates skill telemetry, and corrects live response history.

## Workspace clarity and accessibility

- **Optional Clarity appearance** improves surface separation, borders, focus
  indicators, and light/dark contrast without changing typography.
- **Resizable panes** remember sidebar width, history width, and split-view
  proportions. Resize handles support keyboard adjustments and reset.
- **Consistent motion** adds pane slides and dialog/menu transitions while
  honoring reduced-motion and Motion Off preferences. Static progress labels
  remain available when animation is disabled.
- **Keyboard navigation** improves workspace tabs, tab actions, tooltips, and
  the command palette, including focus restoration after dismissal.
- **Recorded details** expose session metadata and prompt/response timing
  through expandable sections without cluttering the default view.
- Narrow-window overlays span the workspace correctly, and terminal repainting
  handles display-scale changes.

## Checkout and session reliability

- **Keep the current checkout by default.** Existing managed directories retain
  their files and checked-out state without a replacement confirmation.
- **Restore missing checkouts** from their registered commit or recorded ref.
  Recovery fetches the recorded ref when necessary, then falls back to remote
  `master` when the previous state cannot be recovered.
- Restored worktrees are detached so recovery does not move shared branches.
  Recovery does not delete existing directories or override worktree locks.
- Sessions reuse their saved checkout even when the original task attachment
  is no longer present. Features with multiple task worktrees offer an explicit
  checkout selection, including when moving and relaunching a session.
- Moving a session to another feature clears its old checkout binding.
- **Stable desktop origin** reuses the backend port across restarts when
  available, preserving origin-scoped tabs and preferences.

## Skill and MCP telemetry

- **Separate skill activity** distinguishes repository, IDE, CLI, and unknown
  sources in Usage and feature dashboards.
- Actual CLI invocations are separate from IDE context preparation and
  successful live context injection. Replay-safe event identities prevent
  duplicate invocation counts.
- **Tokens and AI credits appear only when explicitly available.** Missing
  metrics remain unavailable; session totals are not allocated among skills.
- Bounded, indexed reads report when recent skill history exceeds the display
  window. Public invocation metadata is retained, not skill instruction bodies.
- **MCP token columns and token ranking are removed.** Measured calls, traffic,
  timing, and explicitly attributed credits remain available.

## Prompt history and Planner

- **Completed replies stop showing "Generating response".** Recorded turn-end
  events take precedence over recent usage accounting, even while the CLI
  database is still saving the turn.
- Open response dialogs update as history refreshes, including when a live
  turn receives its persisted index. The duplicate generating label is removed.
- Repeated prompts remain distinct, and injected bootstrap instructions are
  hidden while embedded user requests remain visible.
- Planner session launches preload the task prompt into the interactive CLI
  once, rather than opening a blank session or replaying it on every reopen.
- Planner tasks for the same date and repository reuse their existing dated
  parent folder instead of creating duplicate buckets.

## Release channel

The release workflow verifies the exact tagged commit on Windows, Linux, and
macOS before building Windows and macOS installers. Backend and UI coverage
thresholds remain unchanged; the desktop harness is also part of verification.

Everything from 0.19.8 is retained. Back up important workspace data before
trying this prerelease. Installer provenance manifests retain their unqualified
status.
