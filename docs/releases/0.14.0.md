# AI Project Studio 0.14.0

**Unsigned prerelease.** These installers are not production-qualified. Windows
may show an unknown-publisher or SmartScreen warning. The macOS build is unsigned
and not notarized; Gatekeeper may block it. Version 0.10.3 remains the stable
release.

**Upgrade note:** the entire `0.11.x` line is superseded and marked known-bad.
Upgrade past it.

This minor release makes usage a first-class, durable part of the workspace:
usage now follows features and sessions when they move, survives their deletion,
and rolls up into a dedicated analytics view.

## Usage attribution & retention

- **Usage follows the work.** Moving a session between features, or a subfeature
  under another feature, carries its recorded usage with it, so feature-level and
  session-level totals stay correct after reorganizing.
- **Deleting no longer erases history.** Closing a session or deleting a feature
  retains a summarized usage record instead of dropping the credits from your
  totals, so monthly and yearly figures remain accurate. (Moving still transfers;
  only deletion summarizes.)
- **Feature-level usage stays with the feature.** Whatever usage a feature
  accrued remains attributed to it even after its sessions or subfeatures are
  deleted.
- Metasession usage is included in every one of these calculations.

## Consolidated usage view

- **A dedicated Usage menu** in the IDE shows consolidated usage by
  **day / week / month / year**, including retained usage from deleted work.
- **General IDE-level metasession usage** has its own section with the same
  day/week/year breakdown, model information, and a clear reason each credit was
  consumed.
- The landing view stays simple and legible; you can drill in as far as you want
  without the summary getting noisy.

## Reliability

- New persistence for usage rollups, attribution, and retained usage, plus the
  rollup service, all land with full test coverage.
- At the release commit the gated source builds cleanly and passes the backend
  and UI coverage gates at 100% line/branch/function/statement coverage.

## Known limitations

- Live GitHub and Azure DevOps operations, installed Copilot/Agency CLI
  processes, authenticated MCP child servers, and a real warm metasession under
  provider load still require an environment qualification run.
- Credits remain genuinely unknown for providers that do not report usage; the
  view shows the unknown state and the tokens it does have rather than inventing a
  cost.
- Windows and macOS installer upgrade/restore qualification is not complete.
  Signing is intentionally omitted from this prerelease; macOS cannot
  self-install updates until signing and notarization are available.

Back up important workspace data before trying this prerelease. Installer
provenance manifests are included and retain their unqualified status.
