# AI Project Studio 0.19.2

**Unsigned prerelease.** These installers are not production-qualified. Windows
may show an unknown-publisher or SmartScreen warning. The macOS build is
**ad-hoc signed but not notarized** (no Apple Developer ID yet); Gatekeeper still
gates it behind the quarantine prompt. No automatic-update feed is published.

> **macOS: "AI Project Studio is damaged and can't be opened"?**
> That message appears when macOS quarantines a downloaded app it can't verify.
> After dragging the app to `/Applications`, clear the quarantine flag once:
>
> ```bash
> xattr -dr com.apple.quarantine "/Applications/AI Project Studio.app"
> ```
>
> Then open it normally. This build is ad-hoc signed, so Apple Silicon no longer
> reports it as "damaged" — you'll get the standard "unidentified developer"
> prompt instead, which the command above resolves.

This patch release makes the **New Task** agent faster and easier to follow, and
sharpens the Review Board and MCP tooling.

## New Task

- **Fast implementation**: single-slice work skips the manager review turn and
  verification is leaner — one scoped build/typecheck instead of a full
  build-test-and-fix loop — so implements that used to take many minutes now
  finish quickly. Tester workers run only the tests related to their slice.
- **Visibly parallel teamwork**: the implement phase renders its workers side by
  side and keeps the team forming in view while they run.
- **Full-screen activity log and per-file progress**: the analysis/activity log
  can be expanded full screen, with per-file progress bars during implementation.
- **Accurate file diffs**: diff base resolution is fixed and each change shows
  the agent that owns it.

## Review Board

- **PR-level review comments**: when no precise line anchor exists, a comment can
  still be left at the pull-request level instead of being dropped.

## MCP

- **Longer tool-discovery client timeout**: inspecting MCP server tools no longer
  times out prematurely on Windows, where process spawn and cleanup overhead
  could exceed the previous client-side limit.

Everything from 0.19.1 (and earlier) is retained: the New Task visual planning
experience, the feature rename during planning with the attached plan document,
and Metasession provider selection.

The release workflow independently gates the exact release commit on Windows,
Linux, and macOS. Backend and UI coverage remain at 100%; the desktop harness
regression suite passes. Coverage thresholds and timeouts are unchanged.

The known limitations documented for 0.18.0 still apply. Back up important
workspace data before trying this prerelease. Installer provenance manifests
retain their unqualified status.
