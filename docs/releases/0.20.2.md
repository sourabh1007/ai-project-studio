# AI Project Studio 0.20.2

**Unsigned prerelease, not production-qualified.** Windows may show an
unknown-publisher or SmartScreen warning. macOS installers are ad-hoc signed,
not notarized; Gatekeeper may require explicit approval. No automatic-update
feed is published. Back up important workspace data before trying this release.

This patch includes the reliability improvements prepared for 0.20.1 and fixes
the Intel macOS UI gate issues that blocked its publication. The unsuccessful
`v0.20.1` tag remains unchanged; no release was published for it.

## Review Board and persistent Agency workers

- Recover missing immutable Git target objects needed to prepare a review.
- Maintain the saved warm-worker target using persistent, provider-owned ACP
  processes for Copilot and Agency. Initialize native sessions before marking
  workers idle and apply concrete models before dispatch.
- Use all available warm review workers, including manifest-backed reviews.
  Reviews requested during startup queue at the configured capacity instead
  of locking the whole review to its first ready worker.
- Retry failed steps up to five times by default, retire unhealthy workers,
  and switch retries while preserving completed perspectives and the overall
  review deadline. Keep review workers tool-free and contexts isolated.
- Stop Agency descendant processes before disposing their parent on Windows.
  Native authentication and admission limits can still block readiness;
  exhausted retries remain explicit failures.

## Startup, Explorer, MCP and desktop

- Enable installed CLI choices at startup and preserve safe provider switching.
- Keep planned tasks available while users answer native setup questions.
  Studio does not answer authentication or permission prompts for the user.
- Show animated Explorer/workspace loading overlays and restore terminal
  geometry after setup input.
- Resolve Windows npm/npx MCP launchers without a shell.
- Enable manual source-build update checks, surface retryable errors and fall
  back to the repository's public release feed on GitHub API rate limits,
  without bypassing installer trust checks.
- Confirm closing with the app's branded icon and a clear shutdown explanation.
  **Keep open** leaves work untouched; accepted closes retain cooperative
  cleanup. Verified update/relaunch shutdowns do not prompt again.

## Deletion feedback and terminal cursors

- Report unconfirmed producer shutdown as a recoverable conflict rather than
  an opaque server error. Keep deletion blocked until every owner confirms it
  has stopped; preserve bounded conflict retries.
- Verify the feature and its known descendants read-only after an ambiguous
  deletion response. Close their views only when their absence is confirmed;
  never blindly repeat a failed or disconnected destructive request.
- Keep deletion feedback compact with counts, expandable details, per-row status
  icons, truncated names with full-name tooltips and **Clear completed**.
  Active and failed operations remain available; fixing the icon/text columns
  prevents the spinner from stretching across the panel.
- Hide inactive terminal carets and disable Alt-click's synthetic arrow-key
  cursor movement. Native ANSI cursor positioning and visibility remain intact.

## Release gate reliability

- Wait for asynchronously loaded metasession settings before asserting the
  configured slot count, rather than treating the initial default as final.
- Scope Explorer ownership checks to the relevant feature, menu and dialog,
  retaining the same visible-role assertions and every folder-insertion case.
- Preserve existing timeouts, coverage thresholds and all four platform gates.

## Evidence and limitations

Local source validation passed the build/typecheck, backend and UI coverage
gates, and 280 desktop harness tests. Native Agency initialization, model
selection, idle persistence and process exit were checked without an AI prompt;
the live development app reported ten initialized idle workers.
Deletion recovery and cursor-output regressions passed. An isolated Electron
renderer also verified native cursor hide/show, exact ANSI positioning, focus
restoration and absence of an unfocused ghost caret without sending CLI input.
The actual deletion component was measured at desktop and narrow widths:
fixed-width aligned icons, bounded scrolling, truncated names and no horizontal
panel overflow.

These checks do not certify a real Review Board inference end-to-end.
Authentication, provider outages and bounded admission/retry limits still apply.
The release workflow gates the exact tagged commit on Linux, Windows, Apple
Silicon macOS and Intel macOS before publishing Windows x64 and macOS arm64/x64
installers with SHA-bound candidate manifests. Signing, notarization and
production qualification remain separate; this prerelease is not marked latest.
