# AI Project Studio 0.18.0

**Unsigned prerelease.** These installers are not production-qualified. Windows
may show an unknown-publisher or SmartScreen warning. The macOS build is unsigned
and not notarized; Gatekeeper may block it. No automatic-update feed is published.

This minor release improves review continuity, MCP management, resource
visibility, and desktop settings persistence.

## Review Board

- Imported PRs start their reviews automatically. Opening a bulk tracker no
  longer queues the same reviews again.
- Completed perspective results persist for the reviewed commit and change
  graph. Retry incomplete sections without discarding successful results.
- Completed reviews offer a confirmed **Approve PR** action that submits a real
  provider approval. Changed PR heads or stale review evidence block approval.
- Finding comments can be edited before confirming **Post and resolve**, with
  validation of the reported file and line.
- Bulk review rows expose live progress, elapsed review time, and reported
  agent AI-credit usage.
- PR dashboards include a clickable PR link, branch and author information,
  reviewed commit, file count, and checkout details when available.

## MCP management and usage

- Server cards distinguish app-owned, provider built-in, and custom servers.
  Separate **Tools**, **Auth/Reauth**, and **Configure** controls replace the
  combined flow.
- Authentication stays disabled unless a check reports required sign-in or
  expired credentials; actionable authentication is red. Unknown status and
  timeouts are not treated as authentication failures.
- Tool discovery shows live progress and safe command previews. Supported
  authentication jobs retain their connection while displaying current sign-in
  prompts; closing the dialog cancels the attempt.
- Configuration offers cached command options and suggestions.
- Workspace and feature usage views rank MCP servers by calls, traffic, tokens,
  or AI credits where those metrics are available. Supported CLI logs supplement
  proxy observations with deduplicated MCP calls.

## Resources and worktrees

- Live resource views separate system, app, and individual-process CPU and
  memory, plus disk usage for app data, worktrees, logs, and caches.
- Log and cache cleanup refreshes resource values. Worktree management opens the
  corresponding Settings page.
- Worktree removals run asynchronously with bounded concurrency. Inventory
  refreshes show cleanup progress, failures, and leftover worktree folders.
- Feature cleanup deduplicates shared checkout paths and preserves recovery
  information when removal fails.

## Desktop experience

- Appearance and terminal preferences persist in desktop user data across
  restarts, even when the local backend port changes. Open windows share updates.
- Compact typography, controls, surfaces, and borders are aligned across the IDE.
- Removing a feature or session closes its corresponding workspace views.

## Known limitations

- Reviews can still fail for genuine provider, repository, or analysis errors;
  failures remain visible rather than being reported as successful reviews.
- Per-MCP token and AI-credit attribution is unavailable unless explicitly
  reported. Historical log backfill is gradual; unsupported log formats cannot
  be counted, and conservative overlap handling can undercount calls.
- Successful tool discovery does not guarantee permission for every tool.
- Persisted perspective results do not restore elapsed-time measurements.
- Legacy appearance migration reads the current origin only; preferences left
  solely under a different old localhost origin are not automatically recovered.
- Windows and macOS installer upgrade/restore qualification is incomplete.
  Signing is intentionally omitted from this prerelease.

Back up important workspace data before trying this prerelease. Installer
provenance manifests retain their unqualified status.
