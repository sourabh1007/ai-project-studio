# AI Project Studio 0.19.5

**Unsigned prerelease.** These installers are not production-qualified. Windows
may show an unknown-publisher or SmartScreen warning. The macOS build is
**ad-hoc signed but not notarized** (no Apple Developer ID yet); Gatekeeper still
gates it behind the quarantine prompt. No automatic-update feed is published.

> **macOS: "AI Project Studio is damaged and can't be opened"?**
> That message appears when macOS quarantines a downloaded app it can't verify.
> After dragging the app to `/Applications`, clear the quarantine flag once:
>
> ```bash
> xattr -dr com.apple.quarantine "/Applications/AI Project Studio.app"
> ```
>
> Then open it normally. This build is ad-hoc signed, so Apple Silicon no longer
> reports it as "damaged" — you'll get the standard "unidentified developer"
> prompt instead, which the command above resolves.

This release adds a dedicated **Planner** — a dated task checklist that lives
next to your workspace, with priorities, quick-add assists, a backlog, and
on-demand AI summaries.

## Planner

- **Dated day view**: plan by day with a movable date heading — step back to
  review past days or forward to plan ahead, and backfill any date. The date is
  the heading, not a field on every row.
- **Quick-add assists**: as you type a task, the Planner can autocorrect the
  word you just finished, suggest titles from your history, and auto-format the
  title when you add it. Each of the three is independently toggleable from
  **Settings → Appearance**.
- **Priorities and launches**: tag a task's priority and launch it straight
  into the **New Task** planner, a **Review Board** (for PR tasks), or a plain
  **session** — grouped under a per-day parent so a day's work stays together.
- **Backlog**: defer a task to the backlog instead of losing it; the backlog
  page (reachable only from the Planner) remembers the day each task was
  deferred and lets you restore it to today or any custom date. A one-click
  **Move unfinished → next day** rolls the day's open tasks forward.
- **Export**: download a day as Markdown, JSON, or CSV.

## AI summary

- **Summarize a day, month, or year**: the Planner page can generate a concise
  AI summary of what you planned and finished over a chosen scope, with optional
  guidance ("focus on blockers"), and download it as Markdown.
- **Fast by design**: the summary runs as a pooled **metasession** — it leases a
  warm session and returns the moment the model's answer is complete instead of
  waiting out a full CLI start — so a request that previously stalled for
  minutes now returns in seconds. It uses your configured metasession
  provider/model, and its credit usage is attributed and visible in Usage.

Everything from 0.19.4 (and earlier) is retained: live prompt history with
copy/download, clean terminal copy-paste, the New Task "plan is regenerating"
indicator, Review Board emoji reactions, and per-tool MCP usage reporting.

The release workflow independently gates the exact release commit on Windows,
Linux, and macOS. Backend and UI coverage remain at 100%; the desktop harness
regression suite passes. Coverage thresholds and timeouts are unchanged.

The known limitations documented for 0.18.0 still apply. Back up important
workspace data before trying this prerelease. Installer provenance manifests
retain their unqualified status.
