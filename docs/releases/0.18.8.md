# AI Project Studio 0.18.8

**Unsigned prerelease.** These installers are not production-qualified. Windows
may show an unknown-publisher or SmartScreen warning. The macOS build is
**ad-hoc signed but not notarized** (no Apple Developer ID yet); Gatekeeper still
gates it behind the quarantine prompt. No automatic-update feed is published.

> **macOS: "AI Project Studio is damaged and can't be opened"?**
> That message appears when macOS quarantines a downloaded app it can't verify.
> After dragging the app to `/Applications`, clear the quarantine flag once:
>
> ```bash
> xattr -dr com.apple.quarantine "/Applications/AI Project Studio.app"
> ```
>
> Then open it normally. This build is ad-hoc signed, so Apple Silicon no longer
> reports it as "damaged" — you'll get the standard "unidentified developer"
> prompt instead, which the command above resolves.

This patch makes the app support **both AI CLIs — GitHub Copilot and Agency — as
first-class, interchangeable providers**, and pick the right default for your
network automatically.

- **Multi-CLI providers**: Copilot and Agency are now both wired behind the same
  provider abstraction, so MCP, usage/cost analytics, settings, skills, and
  sessions/meta-sessions work equally against either one. You can run either CLI
  (or both) and see usage and status reported accordingly, even though each CLI
  exposes that information differently under the hood.
- **Network-aware default**: on first launch the app picks the default CLI from
  your environment — **Agency** on the Microsoft corporate network, **GitHub
  Copilot** elsewhere. Detection uses explicit overrides (`AI_STUDIO_MS_NETWORK`
  / `CW_MS_NETWORK`) and environment signals first, refined by a best-effort
  endpoint probe that updates the default without needing a restart.
- **First-run install gate**: the generalized setup gate eagerly installs the
  network-default CLI with live progress and installs the other on demand when
  you select it. Installs are silent; you're prompted to log in on first use.
- **Provisioned prerequisites unchanged**: Node.js (required), plus best-effort
  Git and the GitHub CLI, are still provisioned on first launch and added to the
  backend's `PATH`; the Copilot/Agency installers run on top of the managed Node
  via `npm`.

Everything from 0.18.7 (and 0.18.6) is retained: automatic Node.js/Git/gh
provisioning on first launch, the macOS "damaged" packaging fix, the
deterministic release pipeline, the Team-tab time-in-review sort, the right-click
tab menu, the smoother Windows auto-update, and the Agency CLI update notice.

The release workflow independently gates the exact release commit on Windows,
Linux, and macOS. Backend and UI coverage remain at 100%; the desktop harness
regression suite passes. Coverage thresholds and timeouts are unchanged.

The known limitations documented for 0.18.0 still apply. Back up important
workspace data before trying this prerelease. Installer provenance manifests
retain their unqualified status.
