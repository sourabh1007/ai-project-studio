# AI Project Studio 0.11.4

**Unsigned prerelease.** These installers are not production-qualified. Windows may show an unknown-publisher or SmartScreen warning. The macOS build is unsigned and not notarized; Gatekeeper may block it. Version 0.10.3 remains the stable release. No automatic-update feed is published for this prerelease.

## New

- **Full accent color picker.** The Appearance settings no longer limit the accent to seven fixed swatches. The presets remain as one-click shortcuts, and alongside them a color picker and a hex field accept any color you want. Your choice is applied live and persists across restarts, exactly as before.
- Any picked color stays readable. The accent both paints primary buttons (text sits on top of it) and inline links (it sits on top of the panel), so a very pale or very dark pick would be illegible in one of those roles. The app keeps the hue and saturation you chose and adapts only the lightness until the color clears the WCAG AA 4.5:1 threshold for the active theme. A color that is already readable is used exactly as picked, and when a color does have to be adjusted the settings page tells you instead of silently showing a different color.

## Fixes (stability)

- Fixed metasession overload and abandoned AI work. Process-admission limits were too low for the fan-out the app performs, and work whose HTTP request had already been cancelled kept running; requests could time out under load. Cancellation is now propagated so abandoned work stops immediately.
- Fixed Settings showing incomplete metasession and operation information. After a dropped live connection the UI marked the stream as interrupted and nothing ever cleared that state, so live updates froze and operation details stayed stale until a full reload. Reconnecting now performs an authoritative resync.
- Fixed the app starting against an unexpected or stale backend after an upgrade. The desktop shell now verifies the backend's identity and protocol version at startup, and always proves shutdown completed rather than hanging when one cleanup step fails.
- Added diagnostics for AI provider protocol failures, which previously surfaced only as a generic failure with no indication of the cause.
- Hardened the boundaries between the UI, the backend and the desktop shell: server responses and live events are now validated instead of trusted, unguarded desktop-bridge calls that could throw are fixed, and packaging requirements are derived from the source so an installer can no longer ship missing a required file.

## Known limitations

- Long-duration soak, restart and process-count runs have not been completed for this release; the fixes above are covered by automated gates but not yet by sustained real-load testing.
- A separate leak (orphaned provider CLI session processes not being reconciled after a backend restart or crash) is still tracked as part of an active, larger session-reconciliation effort.
- Full packaged/native, upgrade/restore, and supported-platform qualification is not complete. Signing is intentionally omitted from this prerelease.
- Automatic retained-image cleanup is unavailable; deletion is manual because provider-history references cannot be proven absent.
- Automatic installation remains withdrawn in favor of guided release-page installation.

Back up important workspace data before trying this prerelease. Installer provenance manifests are included; their pending qualification status remains accurate after publication.
