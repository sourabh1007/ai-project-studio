# AI Project Studio 0.19.6

**Unsigned prerelease.** These installers are not production-qualified. Windows
may show an unknown-publisher or SmartScreen warning. The macOS build is
**ad-hoc signed but not notarized** (no Apple Developer ID yet); Gatekeeper still
gates it behind the quarantine prompt. No automatic-update feed is published.

> **macOS: "AI Project Studio is damaged and can't be opened"?**
> That message appears when macOS quarantines a downloaded app it can't verify.
> After dragging the app to `/Applications`, clear the quarantine flag once:
>
> ```bash
> xattr -dr com.apple.quarantine "/Applications/AI Project Studio.app"
> ```
>
> Then open it normally. This build is ad-hoc signed, so Apple Silicon no longer
> reports it as "damaged" — you'll get the standard "unidentified developer"
> prompt instead, which the command above resolves.

This release polishes the **Planner** page: a clearer layout, a richer AI
summary experience, and a handful of colour and motion touches.

## Planner polish

- **Filters on top**: the date navigator and filter toolbar (repository, move
  unfinished, export, backlog) now sit above the quick-add box, so you choose
  the day and context before jotting a task.
- **Colour and motion**: a gradient accent on the quick-add box, an
  accent-tinted day chip, a slower slide when you change days, and glow/lift
  animations on the AI trigger, buttons, and the done checkbox.
- **Readable backlog dates**: the backlog restore date field now shows the full
  `YYYY-MM-DD` value instead of clipping it.

## AI summary

- **One-tap AI summary**: a glowing **AI summary** button beside the filters
  opens a modal that asks how you'd like the tasks summarized, then summarizes
  **only** the planned tasks.
- **Markdown and HTML output**: the result renders as formatted Markdown, lists
  the backing tasks with their dates, and can be downloaded as either a
  Markdown (`.md`) or standalone HTML (`.html`) file.
- **Still fast**: the summary continues to run through the warm, pooled
  **metasession**, returning the moment the model's answer is complete; its
  credit usage is attributed and visible in Usage.

Everything from 0.19.5 (and earlier) is retained: the dated Planner with
priorities, quick-add assists, backlog, and launches; live prompt history with
copy/download; clean terminal copy-paste; and per-tool MCP usage reporting.

The release workflow independently gates the exact release commit on Windows,
Linux, and macOS. Backend and UI coverage remain at 100%; the desktop harness
regression suite passes. Coverage thresholds and timeouts are unchanged.

The known limitations documented for 0.18.0 still apply. Back up important
workspace data before trying this prerelease. Installer provenance manifests
retain their unqualified status.
