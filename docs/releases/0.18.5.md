# AI Project Studio 0.18.5

**Unsigned prerelease.** These installers are not production-qualified. Windows
may show an unknown-publisher or SmartScreen warning. The macOS build is unsigned
and not notarized; Gatekeeper may block it. No automatic-update feed is published.

This patch release adds workspace and PR-picker quality-of-life improvements and
smooths the Windows auto-update flow:

- **Team-tab time in review**: the PR picker's Team tab now shows how long each
  pull request has been open ("in review for") as a compact badge, and adds a
  sort control to order a teammate's PRs — and the teammate groups themselves —
  by longest-in-review or newest. The popup also widens responsively while the
  Team tab is active so larger teams stay readable. Pull requests now carry the
  provider's open timestamp (GitHub `createdAt`, Azure DevOps `creationDate`).
- **Right-click tab menu**: right-clicking an editor tab opens a context menu
  with Close this, Close tabs to the left, Close tabs to the right, and Close
  all. Edge actions disable at the ends of the strip, and the menu dismisses on
  outside click, Escape, window blur, or resize.
- **Smoother Windows auto-update**: the update banner now shows explicit
  installing and restarting phases with animated, reduced-motion-aware activity
  indicators, detects a stalled download, and only allows dismissal when no
  install is in flight.
- **Agency CLI update notice**: the IDE already keeps the bundled Agency CLI
  current in the background on every start; now, when that check actually
  installs a new version, the app shows a dismissible "Agency CLI updated"
  popup on open (with the previous → new version when known). A no-op
  "already latest" check stays silent.

The release workflow independently gates the exact release commit on Windows,
Linux, and macOS. Backend and UI coverage remain at 100%; the desktop harness
regression suite passes. Coverage thresholds and timeouts are unchanged.

The known limitations documented for 0.18.0 still apply. Back up important
workspace data before trying this prerelease. Installer provenance manifests
retain their unqualified status.
