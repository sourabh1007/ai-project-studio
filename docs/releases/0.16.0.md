# AI Project Studio 0.16.0

**Unsigned prerelease.** These installers are not production-qualified. Windows
may show an unknown-publisher or SmartScreen warning. The macOS build is unsigned
and not notarized; Gatekeeper may block it. Version 0.10.3 remains the stable
release.

**Upgrade note:** the entire `0.11.x` line is superseded and marked known-bad.
Upgrade past it.

This release documents and ships the **agent platform** and the **New Task**
agent, and refreshes the docs around **metasessions**.

## What's new

- **New Task agent** — attach it to any feature with a linked repository to solve
  a problem end to end: it plans the change for you to review, then implements it
  with a **team of parallel agents** (a lead agent decomposes the plan; developer
  and tester sub-agents each run on their own metasession), commits in an
  isolated git worktree, and opens a pull request.
  - Live **agent hierarchy** with per-agent time, tokens, and AI credits;
    click any agent for its live log, or any changed file for its diff (with a
    full-file toggle).
  - Background-safe: switching windows does not stop planning or implementation,
    and an in-flight run can be cancelled and reset (terminating attached
    processes).
  - PR description is a concise **Problem / Solution** summary.
- **Agent platform** — Review Board and New Task are now first-class attachable
  agents behind one registry: prerequisite gating, namespaced routes/config,
  per-agent usage roll-up, and an **Agents** activity-bar view.

## Documentation

- Rewritten **[docs/agents.md](../agents.md)** — the shipped agent platform and

- New **[docs/features/new-task.md](../features/new-task.md)** — the New Task

- `architecture.md`, `backend-modules.md`, and the READMEs updated to reference

## Reliability

- At the release commit the gated source builds cleanly and passes the backend
  and UI coverage gates at 100% line/branch/function/statement coverage.

## Known limitations

- Live GitHub and Azure DevOps operations, installed Copilot/Agency CLI
  processes, authenticated MCP child servers, and a real warm metasession under
  provider load still require an environment qualification run.
- Credits remain genuinely unknown for providers that do not report usage; the
  view shows the unknown state and the tokens it does have rather than inventing a
  cost.
- Windows and macOS installer upgrade/restore qualification is not complete.
  Signing is intentionally omitted from this prerelease; macOS cannot
  self-install updates until signing and notarization are available.

Back up important workspace data before trying this prerelease. Installer
provenance manifests are included and retain their unqualified status.
