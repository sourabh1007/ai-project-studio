# AI Project Studio 0.17.2

**Unsigned prerelease.** These installers are not production-qualified. Windows
may show an unknown-publisher or SmartScreen warning. The macOS build is unsigned
and not notarized; Gatekeeper may block it. Version 0.10.3 remains the stable
release.

**Upgrade note:** the entire `0.11.x` line is superseded and marked known-bad.
Upgrade past it.

A patch release that makes Bug Bash runs observable scenario-by-scenario,
tightens the prepare-step questions, and lets the run view use the full window.

## Bug Bash

- **Live per-scenario progress** — each tester now executes its assigned
  scenarios one at a time and streams a per-scenario status. The run view shows
  the scenario currently under test as an animated loader, fills completed
  scenarios dark green, and leaves queued scenarios unchanged, so you can watch
  the tester team advance in real time instead of waiting for a single batch to
  finish.
- **Testers scale to the workload** — the lead now sizes the tester team to the
  number of accepted scenarios (about four scenarios per tester) rather than a
  fixed small cap, so larger runs fan out across more testers.
- **Concise prepare-step questions** — the analyst asks short, single-fact
  questions with pickable answer options, so a run can be prepared with a few
  clicks instead of long free-text. Questions auto-generate when you continue
  from the describe step, with an analysing/skeleton transition.
- **Explicit permission & package checks** — the analyst now derives the
  access/permissions and packages/tools a scenario needs and asks about any not
  already confirmed, so fewer scenarios end up blocked mid-run.
- **Numbered scenarios** — review cards and run rows carry a scenario counter.

## Fixes

- **Live team timers no longer freeze** — the one-second run clock stopped
  restarting on every streamed event, so per-agent and team elapsed times now
  advance smoothly during a run instead of appearing stuck.
- **Full-width run view** — Bug Bash opts out of the narrow readability cap and
  expands to fill the window, so the tester team and scenario grids use the
  available space.

## Reliability

- At the release commit the gated source builds cleanly and passes the backend
  and UI coverage gates at 100% line/branch/function/statement coverage, plus
  the desktop harness regression suite.

## Known limitations

- Running each scenario as its own turn makes a run more thorough to observe but
  uses more model turns than the previous single-turn-per-tester batch.
- Windows and macOS installer upgrade/restore qualification is not complete.
  Signing is intentionally omitted from this prerelease.

Back up important workspace data before trying this prerelease. Installer
provenance manifests are included and retain their unqualified status.
